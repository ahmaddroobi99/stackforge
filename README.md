# stackforge

Layered hardware simulation: start at a resistor, end at a pipelined RISC-V core, without leaving the tool. Every layer is a plugin over one shared kernel.

**Status:** slices 1–3 are implemented and tested. Slices 4–8 are intentionally not stubbed.

See the repository files for the kernel, L0 MNA, L2 gates, and L4/L5 RISC-V pipeline.
